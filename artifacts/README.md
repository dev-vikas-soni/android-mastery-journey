# Artifacts

## Purpose
This track stores public-facing outputs created from the learning journey: articles, talks, diagrams, presentations, and media.

## What belongs here
- Drafts and published articles
- Conference notes and presentation materials
- Diagrams and supporting visual assets
- Media files that support talks or documentation

## Naming convention
Organize files by output type and keep them easy to browse by audience and format.

## Examples
- [artifacts/publications/](artifacts/publications/)
- [artifacts/talks/](artifacts/talks/)
- [artifacts/diagrams/](artifacts/diagrams/)

## Future expectations
This track will become the public portfolio layer of the repository as the body of work grows.
