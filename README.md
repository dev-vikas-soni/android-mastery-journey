## Mission
This repository is a long-term public knowledge base for the journey from Senior Android Engineer to Android Framework Expert.

## Why this repository exists
The goal is to document practical learning, deep technical understanding, and professional growth in a way that remains searchable, structured, and useful for years.

## Current Goal
Build a durable foundation across Android internals, Kotlin, Compose, performance, memory, concurrency, networking, storage, security, testing, architecture, open source, and career development.

## How the repository is organized
The repository is structured around three parallel tracks:
- [knowledge/](knowledge/) for theory, deep-dive notes, and reference material
- [labs/](labs/) for practical exercises, weekly experiments, and retrospectives
- [artifacts/](artifacts/) for blogs, talks, diagrams, presentations, and media

## Learning Philosophy
- Learn by building, writing, and reviewing.
- Connect theory with platform implementation details.
- Capture patterns that are reusable in production systems.
- Keep notes concise, structured, and linked to source material.
