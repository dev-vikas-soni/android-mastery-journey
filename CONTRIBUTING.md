# Contributing

## Overview
Contributions are welcome as this repository grows into a durable public knowledge base.

## How to contribute
- Add new notes or topic pages in the appropriate folder.
- Follow the existing markdown structure and naming conventions.
- Prefer clear, evidence-based writing over speculative summaries.
- Link to official references where possible.

## Writing guidelines
- Use concise, professional language.
- Keep sections consistent across documents.
- Include placeholders for future expansion when needed.
- Use relative links whenever possible.

## Review expectations
- Ensure content is accurate and relevant.
- Avoid empty files or incomplete notes.
- Keep the repository organized and easy to navigate.
